# Live School System

A VS Code extension that opens a live operating dashboard for a school management system.

## Features
- Real-time class and attendance overview
- Teacher and student overview
- Assignment tracking and due dates
- Announcements and emergency notices
- Classroom schedule and status feed
- Simulated live updates every few seconds

## Run it

```bash
npm install
npm run compile
```

Then open the Command Palette in VS Code and run:

`School: Open Live School System Dashboard`

## Files
- `package.json` — extension metadata and commands
- `src/extension.ts` — VS Code extension logic and webview dashboard
- `tsconfig.json` — TypeScript configuration
